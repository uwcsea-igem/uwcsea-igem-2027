# Data provenance

`processed/` contains small, reproducible derived artifacts. `raw/` is ignored by Git; use a reviewed Release or configured Git LFS for shareable large files. Never upload the private chat export, media, contact details or Classroom access codes.

The initial literature observations live in `software/tipcraft/benchmarks/retro-t7-t3/cases.csv`, with source URL, locator and interpretation per row. They are manually curated qualitative labels, not digitized quantitative EOP values. No experimental raw data or structural predictions have been collected. The evaluator's JSON is a derived baseline report; regenerate using the root README command. Original publications retain their terms; no full text or source figure is redistributed.
