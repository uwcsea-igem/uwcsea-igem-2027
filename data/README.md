# Data provenance

`processed/` contains small, reproducible derived artifacts. `raw/` is ignored by Git; use a reviewed Release or configured Git LFS for shareable large files. Never upload the private chat export, media, contact details or Classroom access codes.

The initial literature observations live in `software/tipcraft/benchmarks/retro-t7-t3/cases.csv`, with source URL, locator and interpretation per row. They are manually curated qualitative labels, not digitized quantitative EOP values. No experimental raw data or structural predictions have been collected. WIsH reference genomes and compiled source/models are under ignored `raw/wish/`; retrieval URLs and sequence hashes are in `software/tipcraft/benchmarks/retro-t7-t3/wish-inputs.json`. Small independent numeric scores, upstream logs and anonymous-run controls are versioned in `processed/wish/`; `processed/retro-t7-t3-wish.json` is their post-score evaluation. WIsH retains GPL-3.0; its executable/source is not redistributed here. The evaluator's JSON is a derived baseline report; regenerate using the root README command. Original publications retain their terms; no full text or source figure is redistributed.
