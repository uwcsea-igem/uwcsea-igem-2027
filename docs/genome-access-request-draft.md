# Public genome access request — unsent draft

Prepared for review. No author has been contacted and no response or engagement is claimed.

**To:** Corresponding authors of *Prediction of strain level phage–host interactions across the Escherichia genus using only genomic information* (DOI: 10.1038/s41564-024-01832-5).

**Subject:** Access to the published Picard collection genome assemblies

Dear authors,

We are preparing a reproducible retrospective evaluation for a student research software project. We would like to use the published Picard collection assemblies associated with Figshare DOI 10.6084/m9.figshare.25941691.v1.

The public file download and version-download endpoints currently return HTTP403 in our environment. The issue has also been reported on a second computer. We successfully retrieved your Zenodo publication archive (10.5281/zenodo.13831957), but found no bacterial genome assemblies in its files or stored history; the five newer public main-branch snapshots also provide no genome files.

Could you point us to an accessible authoritative download or an exact-byte mirror of the 403 deposited FASTA files? We have retained the published filenames, file IDs, sizes and MD5 checksums for authentication. We would preserve the supplied sequences and source attribution.

Our immediate purpose is public-data method evaluation; no new recognition heads or synthesis-ready designs are being generated.

Thank you for making the collection available.
