# Strain-level scoring through a matched grouped evaluation

Updated 2026-11-08. **The next experiment will test whether paired phage–host features add ranking signal beyond host background alone.** The [prospective design policy](../software/tipcraft/benchmarks/receptor-resource/secondary-model-design-policy.json) fixes the model settings and comparison rules before any biological model fit. Final genomic groups and exact eligible memberships are pending, so this is a design freeze, not a complete executable run manifest or an executed prediction result.

## Scientific question

Protein-family occurrence provides a concrete hypothesis for strain discrimination: strains can differ in encoded surface structures and intracellular determinants, while phages can differ in the proteins involved in host interaction. A whole-proteome classifier could learn associations between these differences and the source assay. This is a hypothesis to test against source controls, not a demonstrated recognition mechanism. Natural T7 recognition of rough LPS is not modelled as docking to an ordinary protein receptor. A whole-genome association score cannot identify gp17 binding, productive infection, or tail-fibre assembly compatibility.

The independently sourced BASEL–ECOR resource supplies measured host-response contrasts without downloading the blocked Picard collection. Its spot-clearance endpoint remains distinct from the original Ando plaque observations. Source and target outcomes have already been inspected during method development; all subsequent results remain exploratory retrospective evidence.

## Fixed candidate and controls

Use the existing pinned gene calls and separate host/phage protein-family vocabularies. In each training block, use MMseqs 18 with the existing pilot parameters: coverage 0.8, minimum identity 0.4 and sensitivity 7.5. Preserve the pilot's other defaults and record their effective values. Search held-out proteins against all frozen training proteins; retain families found in more than one unique training genome and consolidate identical training occurrence patterns. Training never includes held-out genomes or the BW25113/T7 technical annotation controls. Zero vectors remain explicit and are reported alongside protein-assignment coverage; they are not interpreted as negative infection labels.

Fit three scopes: paired, host-only and phage-only. Each receives the same training rows, labels and train-derived weights, with its own scope-restricted feature selection. Fix RFE and final CatBoost to 500 trees, depth 4, learning rate 0.1, L2 regularization 3, seed 2027 and one fitting thread. For each scope, retain `K=min(100,P)` columns and use RFE removal step `max(1,int((P-K)/10))`, where `P` is that scope's available training feature count. The tree settings follow the implementation settings documented in [the fitting review](18-training-protocol-and-component.md); the feature cap and fixed final configuration are untuned engineering choices, not claimed optimal settings or an exact reproduction of the paper. An empty feature scope or globally single-class training set is HOLD. Use the existing `per_phage_log10` training-only weight formula. No grid search, evaluation-set early stopping, calibration or target-dependent threshold is introduced.

The locked learning environment remains Python 3.12.5/CatBoost 1.2.7. Raw margins are ranking scores, not infection probabilities. A constant tied score supplies the 0.5 ranking baseline. The phage-only model should tie host candidates within a query scored by one model; a violation indicates an input or implementation problem. Host-only performance tests the alternative explanation that a preferred host background accounts for an apparent paired-model success.

## Grouped evaluation and score comparability

Apply the existing label-independent hash assignment with seed 2027 to three host-group folds and three phage-group folds. For each of the nine crossed blocks, training contains neither held-out axis; the two mixed quadrants are embargoed. Fit annotation-independent vocabulary construction, occurrence consolidation and supervised selection on that block's training genomes and labels. Each retained observed row is tested once. Insufficient groups, empty training/test blocks or invalid fits yield HOLD; no search for a better split or smaller fold count follows.

**Compare positive and negative hosts only when the same fitted model scored them.** In crossed blocking, one phage's hosts can be evaluated by three different host-fold models. Their raw margins have no shared scale. Pooling those margins into a single host ranking could introduce arbitrary ordering from model offsets. The new [blocked-ranking evaluator](../software/tipcraft/src/tipcraft/blocked_ranking.py) therefore computes concordance within each phage/test-block unit, with ties worth 0.5. It averages informative blocks per phage, phages per relatedness group and groups equally. It reports all units, including single-class units without concordance; it never fabricates their missing contrast.

Every supplied comparator must score exactly the same rows in every block with one declared model identity. The evaluator rejects missing, extra, repeated and nonfinite scores rather than silently selecting a favorable common subset. Model identities are declarations that the final runner must bind to authenticated model bundles. Complete coverage here refers to the explicit input manifest, so the final report must separately disclose exclusions and coverage against the full source roster. Informative mixed-label units, phages and groups are counted separately: complete scoring coverage does not mean every row supplies a ranking contrast. The 60 unobserved source pairs remain unknown. Group and pair counts describe dependence structure; they are not independent biological replicate counts.

## Decision rules and original endpoint

A secondary interaction-attribution screening signal requires complete finite matched coverage and paired group-macro concordance strictly above both 0.5 and host-only on identical units. Report phage-only scores and all group-level paired differences. Any other outcome supplies no positive source interaction-attribution signal. This descriptive screen does not establish statistical significance, broad generalization, receptor causality or transfer from spot clearance to plaques.

The [original native ranking contract](../software/tipcraft/benchmarks/retro-t7-t3/next-method-contract.json) is unchanged: complete six-native-case scores, within-phage positive–negative concordance above 0.5 and above WIsH on the same subset, with matched host-only attribution. T3 is the informative native query; T7 has no negative in this panel. The four exact exchange-construct abstentions remain. Secondary success cannot replace those observations or turn six-case coverage into ten-case coverage. The final source-only fitting and native projection specification must be bound before producing target scores, without tuning against Ando outcomes.

The [native transfer supplement](../software/tipcraft/benchmarks/receptor-resource/secondary-native-transfer-design-policy.json) fixes the final refit behavior before secondary biological scoring. After valid source admission and outer evaluation, refit all three scopes on all eligible source observations with the same settings; project the two original phages and three hosts into frozen source vocabularies. Execute this diagnostic even if source cross-validation disappoints, provided execution prerequisites remain valid. Source performance does not select a different model, feature cap or target candidate set. Freeze the final bundles and complete six-pair score manifest before native label evaluation. Original-target technical-control proteomes may become inference queries, but never training inputs. A favorable native ordering alongside poor source validation cannot override the source decision or establish generalization.

The supplement also binds all five existing native query proteomes explicitly: 49 predicted proteins for T7, 43 for T3, 4,234 for BL21, 4,314 for BW25113 and 4,319 for MG1655. All 15 normalized-DNA/FAA/GFF artifact hashes were rechecked, and each reference sequence hash matches the original WIsH input. These 12,959 predicted proteins therefore preserve the original reference candidate set; no gene caller, feature projection or infection model was run for this inventory. The check authenticates existing annotation artifacts and their reference correspondence, not physical stock equivalence or independent DNA retranslation.
